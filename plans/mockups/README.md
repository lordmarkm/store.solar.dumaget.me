# Builder mockup

[solar-build-picker.html](solar-build-picker.html) is the accepted category-table
interactive concept from 2026-10-10. It is archived as an HTML fragment, not an
Angular component, deployable page or implementation of the backend rules.

It demonstrates multiple rows per category, independent quantities, Add another
versus targeted Change, free-text requirements, selection, compatibility notes
and review-before-append. All products, prices, thumbnails and technical statuses
are illustrative. Preview confirmation changes no account project or inventory.

The conversation preview supplies icons/design controls; a standalone viewer may
not show those host-provided assets. Implementation must use existing KTUI and
verified KeenIcons, real published product pictures and local bundled fonts,
not copy the preview's rendering dependencies into the application.

DOM interaction checks covered add/replace/remove, free text, quantities, totals,
selection, requirements and review. No real app or browser visual checks are
claimed by archiving this fragment. The authoritative behavior is the
[builder plan](../PROJECT-BUILDER-PLAN.md).
